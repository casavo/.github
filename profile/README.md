# Casavo Tech

[Casavo](https://casavo.com) is an all-in-one real estate platform in Italy and France: people
selling or buying a home work with a network of partner agents, backed by Casavo's brand, data and
technology. We build that technology: the platform our partner agents use to run every sale, and
the public sites where people search for a home or value their property. It is built for our own
network, not sold as a product.
